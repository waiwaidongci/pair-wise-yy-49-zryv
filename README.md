# 高校课程标准映射与课程改革审阅平台

面向教研人员、课程负责人和院系审阅人的课程图谱平台，支持培养目标、毕业要求、课程单元、教学活动、考核任务映射，以及有向图检查、覆盖矩阵、拖拽连边、自动保存、批量审核和课程地图导出。

## 技术栈

SvelteKit + Skeleton UI + Svelte stores + SvelteKit Form Actions + TanStack Query + Zod + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62049`，生产构建使用 `npm run build`，`npm start`（node start.js）启动。

## 核心工作流

- 在培养目标、毕业要求、课程、单元和考核之间建立有向映射。
- 自动检查前置关系、覆盖缺口、重复映射和不完整考核证据。
- 课程负责人提交修订，院系审阅人逐条退回、附议或要求补充证据。
- 比较版本覆盖变化，恢复草稿并导出专业课程地图。

## 版本化一致性模型

课程、毕业要求、映射与审阅意见围绕服务端同一份版本化状态工作，客户端只保留快照缓存（不再各存一份草稿）。

- **乐观并发（草稿版本）**：每次写入都携带 `baseVersion`；版本过期时改动不落地（HTTP 409），服务端返回最新快照供页面回退，表单已填内容保留；本次过期送达仍记入服务端操作日志。
- **操作编号幂等**：每条写入带唯一 `opId`，同一编号重复送达只返回第一次结果（重复决定不会二次落库）；网络失败后可通过 `GET /api/ops/[opId]` 按编号查证恢复，不重发、不留半条审阅。批量审阅为单条原子操作，任一校验失败则整批不生效。
- **失效与重算**：课程 / 毕业要求内容或引用映射一旦变更，引用它的未完成审阅标记“已失效”，已锁定但未发布的基线标记失效；覆盖结论在服务端统一计算，随快照持久化，重启后课程、修订与覆盖结论始终一致。
- **发布基线**：`lock` 留存不可变锁定快照，`publish` 留存发布快照（含当时的节点、映射、审阅与覆盖矩阵），随时可查；锁定期间映射与课程内容冻结，可“退回修订”后再改。
- **持久化与恢复**：服务端采用 WAL（预写日志）+ 快照检查点，写入先落 WAL 再提交内存；重启时载入快照并重放日志，包括已落地与已退回的操作编号记忆。数据目录由 `CURRICULUM_DATA_DIR` 环境变量指定（默认 `.data/`）。

### 验证

```bash
npm run verify:engine   # 引擎不变量：并发、幂等、过期退回、失效重算、基线快照、重启重放
npm run check           # 类型检查
```
